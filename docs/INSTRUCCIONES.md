# ConstructIA — Avance 1

Proyecto académico de chatbot basado en reglas con Python 3.10 o superior y NLTK.

El prototipo orienta sobre construcción y renta de maquinaria, recopila datos ficticios durante la sesión y no confirma precios, disponibilidad ni reservas.

Para utilizarlo en Google Colab, abre el cuaderno `ConstructIA_Avance1_V2_Colab.ipynb` y ejecuta las celdas en orden. Las pruebas se hacen con datos ficticios.

# ConstructIA — Tecmilenio

Chatbot académico basado en reglas con Python 3.10+ y NLTK para consultas sobre construcción y renta de maquinaria.

**Código:** `constructia_reglas.py`, `constructia_chatbot.py`, `constructia_pruebas.py`.

**Pruebas:** 18 escenarios ficticios reproducibles, con entradas, intenciones y respuestas. Se incluyen cinco flujos completos.

**Google Colab:** https://colab.research.google.com/github/chrisavm24-dot/ConstructIA/blob/main/ConstructIA_Pruebas_Colab.ipynb

Abre el enlace y selecciona «Entorno de ejecución → Ejecutar todas». Guarda capturas auténticas de las salidas como evidencia del curso.

El prototipo no consulta precios, inventarios ni disponibilidad; tampoco realiza reservas o envíos a proveedores. No uses información personal real en las pruebas.
